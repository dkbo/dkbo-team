# 決策紀錄（跨任務，一行一則，只寫會影響未來的）
- 2026-09-10 定位：一位人類、一位領導、同時 3 到 6 位員工、一個 herdr 視窗；小團隊足以應付九成以上的專案，不往多租戶／數十 agent 的平台走。詳見 docs/design/2026-09-10-external-review-response.md。
- 2026-09-10 不做 event bus：messages.log 與 state 檔可讀、可 grep、進 git，是設計選擇不是過渡方案。
- 2026-09-10 不做 agent registry 與能力評分：三種 kind、六個角色，領導照角色檔選人即可；評分需要的樣本量小團隊永遠不夠。
- 2026-09-10 不做任務 DAG：brief 的波次表就是領導手工壓平的依賴圖，再加一層排程器沒有收益。
- 2026-09-10 不做金額／token 預算：三家 CLI 沒有可 script 的統一計價來源，算出來會是假數字；預算只做時間（逾時）與次數（修復迴圈、QUESTION 上限）。
